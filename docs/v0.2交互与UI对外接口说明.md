# v0.2 交互与 UI 模块对外接口说明

本文档说明 v0.2 单页交互与界面增强阶段在 `modules/interaction/` 与 `modules/ui_render/` 中新增及扩展的全部对外接口，供集成层（`app/`）及下游联调使用。

> **基线与依赖说明**：
> - `EditorInteraction`（`modules/interaction/`）：命名空间 `editor::interaction`，仅链接 `EditorData`（含 `Qt6::Gui` / `Qt6::Core`），不依赖排版、文档或窗口部件库。
> - `EditorUiRender`（`modules/ui_render/`）：覆层与右键菜单位于命名空间 `editor::ui`，`CanvasWidget` 与 `MainWindow` 位于全局命名空间；链接 `EditorData`、`EditorLayout`、`EditorInteraction` 与 `Qt6::Widgets`。
> - 所有 v0.1 原有核心文件（`HitTest.*`、`Selection.*`、`TextBoundary.*`、`InteractionController.*`、`InteractionTypes.h`）保持原有签名与行为不变。

## 一、`modules/interaction` 新增对外接口

### 1. 基础交互与选中类型（[ContainerInteractionTypes.h](../modules/interaction/ContainerInteractionTypes.h)）

#### `enum class ContainerHitType`
分级命中判定返回的命中类别：

| 枚举值 | 含义 |
|---|---|
| `None` | 未命中任何有效区域 |
| `ResizeHandleLeft` / `ResizeHandleRight` | 选中分组/子文本容器或图片的左右缩放手柄 |
| `ResizeHandleTop` / `ResizeHandleBottom` | 选中图片的上下高度手柄 |
| `ResizeHandleTopLeft` / `ResizeHandleTopRight` / `ResizeHandleBottomLeft` / `ResizeHandleBottomRight` | 选中图片的四角等比缩放手柄 |
| `ContainerBorder` | 文本/分组容器拖动边框（`5px` 边缘热区） |
| `FloatingImage` | 图片主体（含文本内浮动绕排图与流式顺序图） |
| `TextFragment` | 文本容器正文内容区 |
| `GroupBlankArea` | 顶层分组内部未落入子容器的空白区 |
| `PageBlankArea` | 页面内部未落入任何容器的空白区 |

#### `struct ContainerHitResult`
- 成员：`ContainerHitType type = None`、`data::ContainerId containerId`、`data::ContainerId parentId`、`int textOffset = -1`。
- 方法：`bool isValid() const`（`type != None`）、`bool isHandle() const`（是否为任意 `ResizeHandle*`）。

#### `struct ContainerSelectionState`
维护当前选中容器 ID 列表（支持 `Ctrl` 多选）：

| 方法 | 说明 |
|---|---|
| `bool isSelected(const data::ContainerId& id) const` | 判断指定容器是否处于选中态 |
| `void select(const data::ContainerId& id, bool multi = false)` | 单选或按多选模式切换加入/取消选中 |
| `void clear()` | 清空所有容器选中态 |
| `bool empty() const` / `size_t count() const` | 判断是否为空 / 返回当前选中数量 |

### 2. 分级命中检测（[ContainerHitTest.h](../modules/interaction/ContainerHitTest.h)）

```cpp
ContainerHitResult hitTestScene(
    const QPointF& paperPos,
    const data::LayoutResult& layout,
    const data::DocumentSnapshot& snapshot,
    const ContainerSelectionState& selectionState,
    qreal zoom);
```

- **参数**：
  - `paperPos`：鼠标在纸张逻辑坐标系下的坐标；
  - `layout`：当前 `LayoutResult`；
  - `snapshot`：当前 `DocumentSnapshot`（用于区分 `Text`、`Group`、`Image` 及是否顶层文本容器）；
  - `selectionState`：当前容器选中集合（只有已选中对象才会探测缩放手柄）；
  - `zoom`：画布当前缩放倍率（内部将边距/手柄容差按 `1 / zoom` 换算为纸张坐标）。
- **判定优先级**：`缩放手柄 > 容器边框(5px) > 图片主体 > 正文文字 > 分组空白 > 页面空白`。
  - **规则约定**：正文顶层容器（`snapshot.root` 下的直接 `Text` 子节点）不暴露左右调宽手柄，其左右边缘返回 `ContainerBorder`；`Group` 与分组内子文本保留 `ResizeHandleLeft`/`ResizeHandleRight`；选中图片支持 8 个角/边手柄。
- **返回值**：`ContainerHitResult`，命中 `TextFragment` 时 `textOffset` 有效。

### 3. 容器与图片拖拽规划引擎（[ContainerDragEngine.h](../modules/interaction/ContainerDragEngine.h)）

#### `struct DragDropPlan`
封装一次实时拖拽/缩放的落点结果与辅助可视化数据：

| 字段 | 说明 |
|---|---|
| `targetParentId` | 目标父容器 ID（顶层顺序为 `root`，文本内浮动图保持原父级 `Text`） |
| `targetIndex` | 在目标父容器子节点列表中的目标插入下标 |
| `localPosition` | 相对目标父内容区左上角的坐标（用于写入 `geometry.position`） |
| `placementMode` | `Flow` 或 `Floating` |
| `targetRect` | 吸附及约束后的目标矩形（纸张坐标，用于绘制跟随预览框） |
| `targetParentContentRect` | 目标父内容区矩形（纸张坐标） |
| `targetParentHighlightRect` | 文本拖入 `Group` 时的分组高亮提示矩形（纸张坐标） |
| `insertionIndicator` | `std::optional<QLineF>`，同级顺序重排的目标插槽水平提示线 |
| `targetDisplaySize` | `std::optional<QSizeF>`，图片缩放时的目标内容尺寸（用于写入 `image.displaySize`） |
| `guidelines` | `std::vector<Guideline>`，触发磁吸后生成的参考线列表 |
| `isValid` | 落点是否合法 |

#### `ContainerDragEngine` 静态接口

| 方法 | 功能与参数说明 | 返回值 |
|---|---|---|
| `planContainerMove(draggedId, draggedType, initialRect, delta, paperPos, baseLayout, snapshot, zoom = 1.0)` | 计算文本/分组容器拖拽的目标父级、同级重排位序及插槽指示线。叶节点文本可以拖入顶层 `Group`。与 `Document::moveNode()` 一致，目标为内层分组或可用内容宽度不足时置 `isValid = false`。同级重排基于拖拽起点的稳定 `baseLayout` 计算前沿阈值，顺序拖动关闭 Y 轴磁吸避免阻滞。 | `DragDropPlan` |
| `planImageMove(draggedImageId, initialParentId, initialRect, delta, paperPos, baseLayout, snapshot, zoom = 1.0)` | 计算图片拖拽落点。浮动图仅允许在原父文本容器可用内容区内移动，并保留原父级与原 `targetIndex`。吸附前的图片框在允许区域内时，逐轴取消会导致越界的吸附及其辅助线。拖入其他容器或最终落点越界、出页时置 `isValid = false`。顺序图片支持顶层/分组流式同级重排。 | `DragDropPlan` |
| `planResizeWidth(draggedId, isLeftHandle, initialRect, delta, parentContentRect, baseLayout, zoom = 1.0)` | 计算左右宽度手柄拖拽后的位置与宽度（左手柄保持右边界锚定并同步更新 `localPosition.x`），夹紧于 `parentContentRect`（最小宽 `50`），带 X 轴磁吸。 | `DragDropPlan` |
| `planImageResize(draggedImageId, handle, initialFrameRect, initialDisplaySize, initialGeometry, delta, parentContentRect, baseLayout, keepAspectRatio = true, zoom = 1.0)` | 计算图片 8 手柄缩放的目标 `targetDisplaySize`、`localPosition` 与对齐线；角点默认等比（可由调用方结合 `Shift` 传入 `keepAspectRatio`），最小显示尺寸 `24×24`，受父内容区约束。 | `DragDropPlan` |
| `applyPlanToCandidateSnapshot(candidate, draggedId, plan, geometry)` | 将合法的 `DragDropPlan` 应用到纯内存候选快照 `candidate`（`plan.isValid == false` 时直接返回 `false`；原地缩放不改变父子关系或排序；跨父移出后按 ID 重新查找目标父容器），随后可直接传入 `composeLayout(candidate)` 实时重排，不改真实 `Document`。 | `bool`（节点与目标父容器合法时返回 `true`） |

### 4. 磁吸与对齐辅助线引擎（[SnapEngine.h](../modules/interaction/SnapEngine.h)）

#### 核心数据结构
- `enum class GuidelineOrientation { Horizontal, Vertical };`
- `struct Guideline`：`orientation`、`position`（纸张坐标轴位置）、`start` / `end`（另一轴向起止点）、`color`（默认 `QColor(255, 0, 127)`）。
- `struct SnapResult`：`snappedTopLeft`、`snappedWidth`、`snappedHeight`、`snappedX`、`snappedY`、`guidelines`。

#### `SnapEngine` 静态接口

| 方法 | 说明 | 返回值 |
|---|---|---|
| `snapMove(currentRect, layout, draggedId, threshold = 6.0, snapY = true)` | 对移动矩形的左/中/右（X 轴）与可选上/中/下（`snapY = true` 时 Y 轴）吸附到页面内容区、其它容器及图片（自动排除 `draggedId` 及其直接子节点；中线仅吸中线，边界仅吸边界）。 | `SnapResult` |
| `snapResizeWidth(currentRect, isLeftHandle, layout, draggedId, threshold = 6.0)` | 宽度调节时仅探测左/右目标边线进行 X 轴磁吸。 | `SnapResult` |

### 6. 选区样式聚合与富文本/图片剪贴板（[RichClipboard.h](../modules/interaction/RichClipboard.h)）

#### MIME 类型常量
- `kRichTextMimeType` = `"application/x-qtdoceditor-richtext+json"`
- `kImageMimeType` = `"application/x-qtdoceditor-image+json"`

#### 核心结构体
- `SelectionStyleSummary`：`bool valid` + 6 个 `std::optional` 字段（`fontFamily`、`fontSizePt`、`color`、`bold`、`italic`、`underline`）。选区全部字符一致时有值，**混合时为 `std::nullopt`**。
- `ParagraphSelectionSummary`：`bool valid` + `std::optional<data::ParagraphAlignment> alignment`、`std::optional<data::ParagraphRole> role`、`std::optional<int> headingLevel`。多段混合时对应字段为 `std::nullopt`。
- `CopiedParagraphMeta`：`role`、`headingLevel`、`format`、`defaultStyle`、`fullParagraph`（是否完整覆盖原段落）。
- `RichTextClipboardPayload`：`plainText`、`formatSpans`（相对 `plainText` 起点的完整解析后 6 项有效字符样式）、`paragraphs`（与 `plainText` 按 `'\n'` 切分片段一一对应）。
- `ImageClipboardPayload`：`sourceResourceId`、`image`、`displaySize`、`placement`、`geometry`、`sourceParentId`、`sourceContainerId`。

#### 函数列表

| 函数 | 功能说明 | 返回值 |
|---|---|---|
| `inspectSelectionStyle(doc, id, range)` | 聚合 `[range.start, range.end)` 内非换行字符的实际有效样式（叠加容器默认 → 段落角色/默认 → 局部区间）；`range.start >= range.end` 时按折叠光标所在位置解析。 | `SelectionStyleSummary` |
| `inspectParagraphSelection(doc, id, focusRange)` | 聚合覆盖 `focusRange` 的段落对齐方式、段落角色与标题级别。 | `ParagraphSelectionSummary` |
| `extractRichTextPayload(doc, id, range)` | 提取选区纯文本、逐 run 完整解析的 6 项字符格式及 1 对 1 段落元信息。 | `std::optional<RichTextClipboardPayload>` |
| `encodeRichTextPayload(payload)` / `decodeRichTextPayload(bytes)` | JSON 序列化与反序列化（含区间有序性与合法字号/颜色校验）。 | `QByteArray` / `std::optional<RichTextClipboardPayload>` |
| `buildRichTextMimeData(payload)` | 构建同时包含 `text/plain` 与 `kRichTextMimeType` 的系统剪贴板数据对象。 | `std::unique_ptr<QMimeData>` |
| `extractImagePayload(doc, id)` | 提取选中图片节点元信息及 `doc.resources` 中的原始 `QImage`。 | `std::optional<ImageClipboardPayload>` |
| `encodeImagePayload(payload)` / `decodeImagePayload(bytes, fallbackImage = {})` | JSON 元信息 + Base64 PNG 编解码（支持传入外部 `QImage` 兜底）。 | `QByteArray` / `std::optional<ImageClipboardPayload>` |
| `buildImageMimeData(payload)` | 构建同时包含 `kImageMimeType` 与标准 `QMimeData::imageData` 的剪贴板对象。 | `std::unique_ptr<QMimeData>` |

### 4. `MainWindow` UI 控件与交互扩展（[MainWindow.h](../modules/ui_render/MainWindow.h) / [MainWindow.ui](../modules/ui_render/MainWindow.ui)）

## 三、集成层（`app/`）典型对接链路参考

1. **容器实时拖拽与提交**：
   - 按下/移动：`hitTestScene(...)` → `ContainerDragEngine::planContainerMove / planImageMove / planResizeWidth / planImageResize` → `applyPlanToCandidateSnapshot(candidate, ...)` → `layout::composeLayout(candidate)` 实时重排预览；
   - 松手：当前落点 `plan.isValid == true` 且候选快照应用成功时，通过 `Document::moveNode` / `Document::setContainerGeometry` / `Document::fromSnapshot`（图片 `displaySize`）一次性提交并压入撤销栈。无效落点丢弃候选快照并恢复原版面。
   - `Esc` 取消：直接丢弃候选快照并恢复原版面，真实 `Document` 全程未改动。
2. **选区样式回显与多段对齐**：
   - 有非空选区时调用 `inspectSelectionStyle(...)` 刷新工具栏（空字段清空字号/字体或取消 `B/I/U` 勾选），折叠光标时保留待用格式 `pendingCharStyle`；
   - 对齐变更时通过 `paragraphRangesFor` 获取所涉段落，逐段仅更新各自 `ParagraphFormat::alignment`，保留每段原有缩进、段距与标题级别。
3. **富文本与图片剪贴板**：
   - 复制/剪切：选中图片优先走 `extractImagePayload` + `buildImageMimeData`；选中文字走 `extractRichTextPayload` + `buildRichTextMimeData`；
   - 粘贴：有 `kImageMimeType` 或系统 `QImage` 时走图片插入；有 `kRichTextMimeType` 时先调用 4 参 `Document::replaceText(id, range, plainText, formatSpans)` 再按 `fullParagraph` 恢复整段属性（不叠加 `pendingCharStyle`）；外部纯文本走常规插入。
4. **光标闪烁与指针锚点缩放**：
   - 监听 `CanvasWidget::caretBlinkChanged` 仅重绘光标局部区域，绘制前检查 `canvas.isCaretVisible()`；
   - 接管 `CanvasWidget::zoomWheelRequested(angleDeltaY, globalPos)`，以 `globalPos` 对应纸张坐标为锚点更新缩放与滚动条。

## 四、已知 v0.1 遗留问题备注

以下两项问题经排查确认位于 **v0.1 交互模块原有文件**，为保持 v0.1 核心源码零改动，本次 v0.2 交互与 UI 模块提交未做修改：

1. **居中 / 右对齐后选区高亮矩形与文字绘制位置不一致**：v0.1 [Selection.cpp](../modules/interaction/Selection.cpp#L28-L36) 中的 `xAt()` 减去了 `line.cursorToX(begin)` 并加回 `f.rect.left()`，在 Qt 6 下会把居中/右对齐偏移量清零，导致 `selectionRects()` 与 `caretRect()` 贴在左边界。
2. **单容器内光标定位偏差**：v0.1 [HitTest.cpp](../modules/interaction/HitTest.cpp)、[Selection.cpp](../modules/interaction/Selection.cpp) 与 [InteractionController.cpp](../modules/interaction/InteractionController.cpp) 处理单容器正文点击、软换行及 `desiredCaretX` 垂直移动；居中/右对齐下因 `caretRect()` 偏左，上下键也会出现落点偏左现象。
