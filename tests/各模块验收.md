# v0.1 各模块验收

排版模块已有固定 C++ 输入和自动结构比较。其余模块的类和方法尚未统一，这里先确定操作与预期结果，由各组按自己的接口编写测试或手工验证。以下项目没有自动连接到正式模块，不能用标准数据自检代替这些验收。

## 文档模块

| 编号 | 操作 | 预期结果 |
|---|---|---|
| D01 | 增加文本、图片和分组，查询节点后调整同级顺序 | ID 唯一且稳定，查询命中正确节点，children 顺序符合修改 |
| D02 | 删除父节点；把节点换到另一个合法父节点 | 子树一并删除；换父节点后树中只保留一份节点 |
| D03 | 尝试重复 ID、自身成为祖先、图片带子节点、超过一层嵌套 | 修改失败且原文档保持有效；逻辑根不计深度 |
| D04 | 在第 07 题中插入、删除、替换局部文本，再增删换行符 | 正文、段落范围、格式范围同步更新，范围采用 UTF-16 且排除段落分隔符 |
| D05 | 修改容器默认格式、段落格式，再局部取消粗体或斜体 | 按容器、段落、局部范围顺序覆盖，false 能显式取消 |
| D06 | 修改几何设置，添加和替换图片资源 | 新快照包含对应约束与资源，图片仍由资源 ID 引用 |
| D07 | 保存快照后继续修改原文档 | 新版本推进，旧快照及其图片内容仍表示旧版本 |

## 交互模块

| 编号 | 操作 | 预期结果 |
|---|---|---|
| I01 | 用第 02、03 题点击图片两侧和中间文字 | 定位到同一正文中的正确插入位置，不能把左右片段视为独立正文 |
| I02 | 用第 06 题分别点击主文和补记 | 容器 ID 正确，进入补记后字符偏移相对补记正文 |
| I03 | 方向键跨行移动、输入、退格、向后删除、回车 | 原文修改正确；重新排版后光标仍指向正确的源位置 |
| I04 | 鼠标拖选、Shift 选择，拖到容器外或进入文本子容器 | 选区始终属于开始选择的文本容器，终点限制在其合法位置 |
| I05 | 同一正文跨绕排片段选择，执行 Ctrl+A | 跨片段选择连续原文；Ctrl+A 仅选择当前文本容器 |
| I06 | 有选区时输入、粘贴、回车、删除、复制和剪切 | 替换或移除正确范围；复制剪切内容符合选区 |
| I07 | 中文输入法连续预编辑、选词和提交 | 预编辑与已提交正文分清，提交不重字，候选框跟随当前光标 |
| I08 | 在第 10 题的 emoji、组合字符和空段落附近编辑 | 光标和删除不落进代理对或组合字符内部；空段落可定位和输入 |

## UI 和绘图模块

| 编号 | 操作 | 预期结果 |
|---|---|---|
| U01 | 在设计器中打开 MainWindow.ui，运行界面 | 菜单、工具栏、中央画布和状态栏可用；主窗口控件通过 ui 文件维护 |
| U02 | 依次绘制全部标准结果，对照 reference | 内容、格式、图片区域和绕排关系正确，允许背景、阴影和显示尺寸不同 |
| U03 | 缩放、滚动后点击、拖选、中文输入 | 坐标变换正确，光标、选区及候选框仍与文字对应 |
| U04 | 查看第 08 题的纸张外区域 | 正文和图片完整显示、可滚动到达；不在纸边截断或自动生成第二页 |
| U05 | 修改选中文字的字体、字号、颜色和强调格式，修改段落角色和标题级别 | 操作传给交互与文档模块，重新排版并反映结果 |
| U06 | 新建文档、取消导出、导出失败或成功 | 入口和反馈明确，失败不应显示成功 |

## 导入与导出模块

| 编号 | 操作 | 预期结果 |
|---|---|---|
| E01 | 使用第 01、07、10 题的同版本输入与标准结果导出 DOCX | Word 能打开并编辑正文，段落、字符格式、标题语义和空段落保留 |
| E02 | 导出第 02、03 题 | 图片可编辑，尺寸与矩形绕排关系正确，正文字符顺序完整 |
| E03 | 导出第 04 题 | 独立图片保留在对应正文之后，不改成段内绕排图片 |
| E04 | 导出第 06 题 | 补记为独立可编辑文本框，主文保持连续，位置和绕排按约定映射 |
| E05 | 向无效位置导出；传入版本不一致的快照与结果 | 反馈明确原因，不宣称导出成功，不混用不同版本 |
| E06 | 在 Word 内修改正文，观察重新换行 | 内容和排版规则仍可编辑；Word 自行换行，不要求与 Qt 逐行逐像素一致 |

第 08 题可检查超页正文是否完整导出；超页浮动图片和文本框映射到后续 Word 页面的规则仍待确认，暂不把其精确页码和落点设为通过条件。第 09 题可辅助检查分组内内容顺序与间距，具体 DOCX 分组表达仍需结合映射草案验证。

本版不验收 Word 导入、双栏、自动分页、跨容器选区、表格公式及 PDF 或 HTML 导出。容器和图片的拖拽缩放、撤销重做、工程文件保存等尚待单独确认。
