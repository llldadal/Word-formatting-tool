# 10 UTF16 偏移和空段落

输入见 Cases.cpp，固定标准见 StandardRecords.inc。坐标以纸张左上角为原点，范围采用 UTF-16 的 [start, end)。

页面 {0, 0, 760, 1000}，内容区 {44, 44, 672, 912}，完整内容范围 {44, 44, 360, 134}。

| 容器 | 父容器 | 框区域 x y 宽 高 | 内容区 x y 宽 高 | 占位区 x y 宽 高 |
|---|---|---|---|---|
| unicode | root | {44, 44, 360, 120} | {56, 52, 336, 104} | {44, 44, 360, 134} |

| 文本容器 | start | end | 可用区域 x y 宽 行高 |
|---|---:|---:|---|
| unicode | 0 | 15 | {56, 52, 336, 26} |
| unicode | 16 | 16 | {56, 78, 336, 26} |
| unicode | 17 | 31 | {56, 104, 336, 26} |
| unicode | 32 | 32 | {56, 130, 336, 26} |
