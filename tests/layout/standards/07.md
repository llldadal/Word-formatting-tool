# 07 多段落和局部格式覆盖

输入见 Cases.cpp，固定标准见 StandardRecords.inc。坐标以纸张左上角为原点，范围采用 UTF-16 的 [start, end)。

页面 {0, 0, 760, 1000}，内容区 {44, 44, 672, 912}，完整内容范围 {44, 44, 672, 172}。

| 容器 | 父容器 | 框区域 x y 宽 高 | 内容区 x y 宽 高 | 占位区 x y 宽 高 |
|---|---|---|---|---|
| rich | root | {44, 44, 672, 158} | {60, 56, 640, 134} | {44, 44, 672, 172} |

| 文本容器 | start | end | 可用区域 x y 宽 行高 |
|---|---:|---:|---|
| rich | 0 | 4 | {60, 56, 640, 34} |
| rich | 5 | 42 | {92, 100, 608, 26} |
| rich | 42 | 45 | {60, 126, 640, 26} |
| rich | 46 | 84 | {80, 164, 608, 26} |
